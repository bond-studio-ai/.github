# Bond Studio AI Repositories

**Looking for a repository?** Start at [`agents-context`](https://github.com/bond-studio-ai/agents-context), the automatically updated index of every active repository by domain.

## Product

- [`web-app`](https://github.com/bond-studio-ai/web-app): Customer room design studio web app.
- [`package-room-visualizer`](https://github.com/bond-studio-ai/package-room-visualizer): Three.js room visualization and editing, used by `web-app` for the layout view and dollhouse.
- [`ios-studio-prototype`](https://github.com/bond-studio-ai/ios-studio-prototype): iOS room capture and design studio app.
- [`mobile-design-studio-v2`](https://github.com/bond-studio-ai/mobile-design-studio-v2): Mobile design studio app.
- [`web-admin`](https://github.com/bond-studio-ai/web-admin): Unified admin web application for Bond internal tools.

## Backend

- [`service-api-gateway`](https://github.com/bond-studio-ai/service-api-gateway): Public gateway that routes requests to the services.
- [`service-layout`](https://github.com/bond-studio-ai/service-layout): Canonical room layouts, scans, and measurements.
- [`service-room-design`](https://github.com/bond-studio-ai/service-room-design): Room designs, presets, styles, and design packages.
- [`service-catalog`](https://github.com/bond-studio-ai/service-catalog): Product catalog API.
- [`service-avery`](https://github.com/bond-studio-ai/service-avery): Product search, AI search, and design generation.

## Platform

- [`infrastructure-pulumi-aws`](https://github.com/bond-studio-ai/infrastructure-pulumi-aws): Main AWS infrastructure as code, one stack per account.
- [`shared-workflows`](https://github.com/bond-studio-ai/shared-workflows): Reusable CI workflows for builds, deploys, and package publishing.

## Documentation

- [`documentation-wiki`](https://github.com/bond-studio-ai/documentation-wiki): Contains documentation related to infrastructure, provisioning and user access to resources.
- [`service-logging-standard`](https://github.com/bond-studio-ai/.github/blob/main/docs/observability/service-logging-standard.md): Logging contract for active Bond services, jobs, workflows, mobile apps, and runtime workloads.
