# Bond Studio AI Repositories

## Action

- [`action-authenticate`](https://github.com/bond-studio-ai/action-authenticate): Initializes authenticated actions and provides access to app token and PULUMI_ACCESS_TOKEN env variable.
- [`action-decrypt-file`](https://github.com/bond-studio-ai/action-decrypt-file): Decrypts a file using OpenPGP

## Documentation

- [`documentation-wiki`](https://github.com/bond-studio-ai/documentation-wiki): Contains documentation related to infrastructure, provisioning and user access to resources.
- [`service-logging-standard`](https://github.com/bond-studio-ai/.github/blob/main/docs/observability/service-logging-standard.md): Logging contract for active Bond services, jobs, workflows, mobile apps, and runtime workloads.

## Experimental

- [`experimental-catalog-ingestion`](https://github.com/bond-studio-ai/experimental-catalog-ingestion) *(archived)*: Catalog ingestion experimental implementation.
- [`unity-scripts/variants`](https://github.com/bond-studio-ai/unity-scripts/tree/main/variants) *(archived)*: 3D model variant creation scripts.

## Infrastructure

- [`infrastructure-pulumi-aws`](https://github.com/bond-studio-ai/infrastructure-pulumi-aws): Infrastructure as code for AWS resources using Pulumi.
- [`infrastructure-pulumi-aws-lowes`](https://github.com/bond-studio-ai/infrastructure-pulumi-aws-lowes): Infrastructure as code for AWS resources using Pulumi.

## Ios

- [`ios-studio-prototype`](https://github.com/bond-studio-ai/ios-studio-prototype): Prototype iOS application for room design studio.
- [`ios-certificates`](https://github.com/bond-studio-ai/ios-certificates): Match appstore certificates storage
- [`ios-capture-sans-lidar`](https://github.com/bond-studio-ai/ios-capture-sans-lidar) *(archived)*: Capture app for iOS that does not use LiDAR sensor.

## Lambda

- [`lambda-image-processing`](https://github.com/bond-studio-ai/lambda-image-processing): Lambda function for processing images.
- [`lambda-gltf-compressor`](https://github.com/bond-studio-ai/lambda-gltf-compressor) *(archived)*: Lambda function for compressing GLTF files.

## Mobile

- [`mobile-design-studio`](https://github.com/bond-studio-ai/mobile-design-studio) *(archived)*: Mobile application for the room design studio.

## Package

- [`package-nodejs-bond-cli`](https://github.com/bond-studio-ai/package-nodejs-bond-cli): NodeJS CLI Tools for Bond Studio AI
- [`package-nodejs-design-gen-checker`](https://github.com/bond-studio-ai/package-nodejs-design-gen-checker): Node.js package for checking design compatibility among all their products.
- [`package-nodejs-materials-list`](https://github.com/bond-studio-ai/package-nodejs-materials-list): Node.js package for generating materials list from room designs.
- [`package-nodejs-bond-ts-core`](https://github.com/bond-studio-ai/package-nodejs-bond-ts-core): Core TypeScript library for bond studio projects.
- [`package-nodejs-access-control-middleware`](https://github.com/bond-studio-ai/package-nodejs-access-control-middleware): Node.js middleware for access control in web applications.
- [`package-nodejs-pulumi-components`](https://github.com/bond-studio-ai/package-nodejs-pulumi-components): Reusable Pulumi components for Node.js infrastructure projects.
- [`package-nodejs-shared-utils`](https://github.com/bond-studio-ai/package-nodejs-shared-utils): Node.js package containing shared utility functions.
- [`package-nodejs-api-contract`](https://github.com/bond-studio-ai/package-nodejs-api-contract): Node.js package for API contract definitions.
- [`package-nodejs-widget-sdk`](https://github.com/bond-studio-ai/package-nodejs-widget-sdk): Node.JS widget SDK for integrating web application via iframe.

## Scheduled

- [`scheduled-nightly-workflows`](https://github.com/bond-studio-ai/scheduled-nightly-workflows): Scheduled jobs for nightly tasks.

## Service

- [`service-catalog`](https://github.com/bond-studio-ai/service-catalog): Service for managing product catalog data.
- [`service-room`](https://github.com/bond-studio-ai/service-room) *(archived)*: Service for returning room data. Replaced by [`service-layout`](https://github.com/bond-studio-ai/service-layout).
- [`service-api-gateway`](https://github.com/bond-studio-ai/service-api-gateway): API Gateway for routing requests to various services.
- [`service-users`](https://github.com/bond-studio-ai/service-users): The users service manages info about people & organizations who use our software
- [`service-access-control`](https://github.com/bond-studio-ai/service-access-control): Service for storing user premission data
- [`service-avery`](https://github.com/bond-studio-ai/service-avery): Avery: the service for all our AI needs.
- [`service-room-design`](https://github.com/bond-studio-ai/service-room-design): A backend service for managing room designs.

## Shared

- [`shared-workflows`](https://github.com/bond-studio-ai/shared-workflows): Templates for shared CI configurations across different projects.

## Unity

- [`unity-model-pipeline`](https://github.com/bond-studio-ai/unity-model-pipeline) *(archived)*: Tools to build asset bundles and manage the catalog.
- [`unity-addressables`](https://github.com/bond-studio-ai/unity-addressables): Assets that get published as Unity Addressable bundles.
- [`unity-addressables-lowes`](https://github.com/bond-studio-ai/unity-addressables-lowes): Lowe's assets that get published as Unity Addressable bundles.
- [`unity-addressables-clay`](https://github.com/bond-studio-ai/unity-addressables-clay): Addressable catalog for Clay dollhouse assets.
- [`unity-bond-cli`](https://github.com/bond-studio-ai/unity-bond-cli) *(archived)*: Command line tool and utility scripts to manage Unity repositories.
- [`unity-ios-configurator`](https://github.com/bond-studio-ai/unity-ios-configurator): App configurator built in Unity.
- [`unity-layout-capture`](https://github.com/bond-studio-ai/unity-layout-capture): Command line tool built in Unity to generate layout view images from room data.
- [`unity-model-checker`](https://github.com/bond-studio-ai/unity-model-checker) *(archived)*: Command line tools built in Unity to validate models.
- [`unity-package-addressables`](https://github.com/bond-studio-ai/unity-package-addressables): Unity package for scripts and assets shared by Addressables projects.
- [`unity-package-airtable`](https://github.com/bond-studio-ai/unity-package-airtable) *(archived)*: Unity package to make calls to the Airtable API.
- [`unity-package-aws`](https://github.com/bond-studio-ai/unity-package-aws): Unity package for talking to Amazon AWS services.
- [`unity-package-bond-core`](https://github.com/bond-studio-ai/unity-package-bond-core): Unity package that provides common classes that projects / packages share.
- [`unity-package-build-plans`](https://github.com/bond-studio-ai/unity-package-build-plans) *(archived)*: Unity package that shows 2D orthographic views of rooms.
- [`unity-package-command-line`](https://github.com/bond-studio-ai/unity-package-command-line) *(archived)*: Unity package to help make command line applications.
- [`unity-package-draco-compression`](https://github.com/bond-studio-ai/unity-package-draco-compression): Unity package that provides Draco compression for 3D models.
- [`unity-package-layout-view`](https://github.com/bond-studio-ai/unity-package-layout-view): Unity package that shows a top-down 2D view of rooms.
- [`unity-package-room-visualizer`](https://github.com/bond-studio-ai/unity-package-room-visualizer): Unity package that shows a 3D view of rooms.
- [`unity-package-server-common`](https://github.com/bond-studio-ai/unity-package-server-common): Unity package for server-side applications.
- [`unity-package-shapes`](https://github.com/bond-studio-ai/unity-package-shapes): Third party Unity package for drawing vector graphics.
- [`unity-room-processor`](https://github.com/bond-studio-ai/unity-room-processor) *(archived)*: Retired Unity room processor, replaced by [`service-scan-processor`](https://github.com/bond-studio-ai/service-scan-processor).
- [`unity-server-side-renderer`](https://github.com/bond-studio-ai/unity-server-side-renderer): Unity project that generates photorealistic renders of rooms.
- [`unity-visual-checker-tool`](https://github.com/bond-studio-ai/unity-visual-checker-tool) *(archived)*: Unity tool for visual checking of 3D models and designs.
- [`unity-web-configurator`](https://github.com/bond-studio-ai/unity-web-configurator): Browser-based configurator built in Unity.

- [`web-ai-search-evaluation`](https://github.com/bond-studio-ai/web-ai-search-evaluation) *(archived)*: Web application for evaluating AI search results across multiple versions.
